Desafío CEAL-SM

Simulador de sensibilización y aprendizaje sobre riesgos psicosociales

Bienvenidas y bienvenidos

Propósito formativo: este simulador busca ayudar a comprender las dimensiones de los riesgos psicosociales y reconocer situaciones que pueden relacionarse con ellas.

Importante: no solicita nombre, cargo, RUT, correo ni otros datos personales. Las respuestas quedan solamente en este dispositivo mientras se realiza el ejercicio y no se envían a ninguna persona.

Este ejercicio no es el cuestionario oficial, no mide el nivel de riesgo de una persona o del establecimiento y no anticipa el resultado de una aplicación real.
